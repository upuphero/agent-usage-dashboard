# v0.0.1 — initial public source preview

This release publishes the current source code. It does not include Windows or macOS installers and is not a production-ready desktop release.

Implemented:

- Tauri 2, React/TypeScript, Rust Core/contracts, SQLite and pinned ccusage sidecar workspace.
- Overview, Providers, Sessions, Settings and independent browser Mock mode.
- API 1.1.0, generated TypeScript DTOs, snapshot replacement, field-level accuracy and safe integer transport.
- Claude Code adapter, controlled process runner, SQLite migrations and native fixture test entry points.
- Settings revision checks, opaque directory selection, persistent dataset/device identities and scan lifecycle handling.

Validated locally: 38 frontend tests, 14 Node/SQL tests, frontend typecheck/lint/production build, contract/dependency/version checks and Windows native ccusage fixtures.

Not yet validated: Rust/Core/desktop compilation and actual Tauri IPC (local MSVC/SDK unavailable), macOS ARM64 execution, installed-package behavior and signed sidecar identity. Complete transitive notices remain a distribution gate.

Supported build targets are Windows x64 and macOS Apple Silicon ARM64. Intel Mac/universal builds are excluded. Existing workflow files are manual-only scaffolding; automatic GitHub validation and packaged release assets are the next implementation step.
