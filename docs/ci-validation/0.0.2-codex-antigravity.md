## 使用

1. 退出旧版 0.0.1（单实例会将第二次启动转回旧窗口）。
2. 解压 portable.zip 的整个文件夹，双击 usage-desktop.exe，保留同目录 ccusage.exe。
3. 数据来源中分别点击 Codex / Antigravity 的“启用并扫描”。找不到默认目录时进入设置选目录。
4. 默认查看最近 30 天，可选今日/本周/本月；按统计时区归日。

免安装不是单文件：保留主程序、sidecar 和 notices。用量缓存/配置仍在用户应用数据目录，与安装版共享身份和历史；需要系统已有 WebView2。profile v1 → v2 原子迁移保留 device/Claude dataset，新增 Codex/Antigravity 各自稳定 UUID；旧二进制不能读取新版 profile，禁止混用。原 SQLite schema不变。

## 来源范围与限制

- Codex：默认用户 .codex，sessions 与 archived_sessions；只冻结用量事件/模型/tier/replay 身份等元数据，不复制认证、用户配置或聊天正文。固定原生 CLI 使用记录的速度档位，未记录部分按标准价格估算。未知字段不补零；API 估算不等于订阅扣费。
- Antigravity：默认 .gemini 的 antigravity、antigravity-cli、antigravity-ide、antigravity-backup，以及 .config/antigravity；读取 conversation SQLite。事务捕获 gen_metadata、steps.metadata、trajectory 时间的白名单 protobuf 子字段，只生成临时用量输入，不复制整个源数据库。ccusage 负责原始事件去重和价格，Core 负责快照替换与聚合。
- 该锁定版本不支持 .pb 文件，出现时保留明确 warning；只有 .pb 且无可读 .db 时拒绝为 schema unsupported，不能显示假零。
- Antigravity CLI 的 outputTokens 为可见输出、totalTokens 包含推理：Adapter 恢复 output_total，并把 reasoning 标为 derived 子集；多模型报告未提供完整模型输出拆分时保持 unavailable。
- Codex inputTokens 已是未缓存输入，不再扣缓存；reasoning 是 output 子集。每个 Provider 的 Daily/Session 与父行/模型子行不相加。
