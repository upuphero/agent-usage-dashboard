# 0.0.6：默认中文与英文界面切换

日期：America/Phoenix 2026-10-05。应用 0.0.6 / API 1.1.0；profile v3 和 SQLite schema 保持不变。

## 实现

- 新增集中式、类型检查的中文/英文文案表与 React 语言 Context，不添加翻译服务或第三方运行依赖。首次使用默认中文；偏好保存在当前浏览器或桌面 WebView 的 `usage-dashboard-language` 中。
- 右上角主题切换按钮旁增加语言图标和当前语言标识。侧边栏、页面标题、筛选、按钮、状态、数据覆盖说明、图表提示、设置和导出反馈一起切换；更新文档语言与窗口页面标题。
- 英文图表使用 K/M/B/T 量级，隐藏中文数值读法；精确 token 和金额的原始值与计算保持不变。状态、错误和已知宿主目录标签本地化，模型/来源标识与用户路径保留。
- 切换语言保留页面、筛选、图表类型和未保存的设置，不改变统计时区或重新扫描。
- 原生目录选择与导出窗口的应用标题跟随界面语言。新增 `localized-dialogs` 能力，使用可选的顶层 IPC language 参数；旧客户端省略参数时仍默认中文，新客户端对旧宿主不发送新参数。标准业务 DTO 保持不变。

## 当前验证

57 项前端 tests、typecheck、lint、生产构建、命令注册、契约生成漂移、依赖边界、版本及 Rust 格式检查通过。新增测试覆盖默认与存储异常、全量英文文案、完整四页面英文无中文 UI 残留、大整数/图表量级、错误消息、单复数及新旧宿主的弹窗语言协商。

浏览器演示实际验证：初始中文；中英文双向切换；英文刷新后保留；筛选、柱状图和未保存来源设置在切换后保留；统计数值不变。英文四页面和版本不兼容错误状态均无中文 UI 残留；干净启动后切换页面的 console warn/error 为空。截图使用合成数据。

原生目录/导出标题回归已添加。本机缺 MSVC link.exe，Rust 原生测试和新的安装包需经现有 CI 验证；本记录暂不宣称原生验证通过或安装包已经生成。
