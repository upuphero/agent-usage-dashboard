# 0.0.4：零用量日期与模型排序

日期：America/Phoenix 2026-10-04。API 1.1.0、Provider 端口、SQLite schema、profile v2 和 ccusage 锁保持不变。

## 实际改动

- Core 在完整权威 Standard Daily 快照中补齐查询的日、ISO 周和月桶：没有使用记录的周期返回 derived zero，趋势经过 0 连续连接。补桶只影响时间序列，不增加总计、记录计数或模型/来源用量。
- 未扫描的缓存、来源明确返回 null、缺失或被拒绝的不完整覆盖保持不可用。完整历史扫描失败仍保留上次成功快照，不把历史清零。
- Overview 查询最多 10,000 天，超过范围返回已有 InvalidQuery，限制补齐时间序列的内存消耗。
- 模型分布默认按 token 降序，可切换 API 估算成本降序；BigInt 与定点字符串精确比较，未使用浮点数重算价格或统计。
- 已知零用量模型默认折叠在最末。当前排序字段不足的模型单独放末尾折叠；null token 但有成本/其他 token 的记录不能称为未使用。费用排序时，有已知费用的这些模型参与正常排序。
